# 12th Nazarene Cub Pack

A lightweight static webpage for the 12th Nazarene Cub Pack.

## Files
- `index.html` — page structure and content
- `style.css` — styling and layout

## Preview locally
Open `index.html` in a browser, or run a small local web server from this folder, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
This is a simple front-end site intended for sharing with families and interested visitors. Updates and family-only information can be shared through WhatsApp or other private channels as needed.
